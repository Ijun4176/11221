# Metro Rift (text prototype)

간단한 콘솔형 메트로베니아 로그라이트 프로토타입입니다. 데드셀 같은 감성을 짧게 경험할 수 있도록 방 탐험, 보스, 잠금 해제 능력(대시) 등을 포함했습니다.

## 실행 방법
1. Python 3.11+가 설치되어 있어야 합니다.
2. 터미널에서 다음을 실행하세요:
   ```bash
   python3 game.py
   ```
3. 안내에 따라 이동(n/s/e/w), 전투(fight), 전리품 획득(loot), 휴식(rest), 상태(status)를 입력합니다.

## 특징
- **랜덤 월드**: 부서진 연구소, 용암 지대 등 다양한 바이옴이 무작위로 배치됩니다.
- **메트로베니아 게이트**: 특정 방은 `dash` 능력이 있어야만 이동할 수 있으며, 보스를 격파하면 해금됩니다.
- **로그라이트 성장**: 전투 시 능력이 조금씩 강해지고, 전리품으로 체력/공격/능력을 강화합니다.

재시작 시마다 다른 배치를 탐험하며 스스로만의 루트를 찾아보세요!
