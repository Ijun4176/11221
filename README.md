# Hollow Flare Prototype

간단한 파이썬/pygame 프로토타입과 메트로베니아 로그라이트 기획서를 담은 저장소입니다. 데드셀에서 영감을 받아 방을 이동하며 적과 싸우고, 대시/점프/공격을 실험할 수 있습니다.

## 실행 방법
1. Python 3.10+ 환경에서 의존성 설치:
   ```bash
   pip install -r requirements.txt
   ```
2. 게임 실행:
   ```bash
   python src/game.py
   # 혹은 시드를 고정하고 싶다면
   python src/game.py 1234
   ```

## 조작법
- 이동: ←/→ 또는 A/D
- 점프: ↑/W/Space (이단 점프 지원)
- 대시: Left Shift (쿨다운 적용)
- 공격: F (근접 짧은 범위)
- 종료: 창 닫기

## 포함된 문서
- `docs/game_design.md`: 핵심 비전과 시스템, 바이옴 아이디어가 담긴 기획서.

## 프로토타입 노트
- 4개의 절차적 방이 좌우로 연결되어 있으며, 대시/점프/공격 느낌을 빠르게 확인할 수 있는 최소 예제입니다.
- 적은 간단한 패트롤과 추적 AI만 탑재되어 있어 전투 루프와 이동 흐름을 실험하는 용도에 집중합니다.
